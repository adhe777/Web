Predefined Functions in JavaScript

1. String

Definition: A String is used to store and manipulate text in JavaScript. It contains letters, numbers, symbols and spaces.

String methods are used to find length, change case, extract characters, search, replace and modify text.

String Functions and Definitions

length - Returns the string length.
toUpperCase() - Converts text to uppercase.
toLowerCase() - Converts text to lowercase.
charAt() - Returns a character at an index.
split() - Splits a string into an array.
reverse() - Reverses array elements.
join() - Joins array elements into a string.
trim() - Removes spaces at both ends.
slice() - Extracts part of a string.
substring() - Extracts characters between indexes.
indexOf() - Finds the first text position.
lastIndexOf() - Finds the last text position.
repeat() - Repeats a string.

2. Math

Definition: Math is a built-in JavaScript object used to perform mathematical calculations on numbers.

It provides methods for rounding, finding square roots, calculating powers and performing other operations.

Math Functions and Definitions

Math.round() - Rounds to nearest integer.
Math.ceil() - Rounds a number upward.
Math.floor() - Rounds a number downward.
Math.sqrt() - Finds the square root.
Math.pow() - Calculates the power of a number.
Math.abs() - Returns the absolute value.
Math.sign() - Returns the sign of a number.
Math.trunc() - Removes the decimal part.
Math.exp() - Calculates e raised to a power.
